
# Google News MCP

An open-source Model Context Protocol (MCP) server that allows AI assistants to search and retrieve news articles from Google News.

## Features

- Search Google News by keywords.
- Retrieve recent headlines.
- Filter news articles.
- Access article titles, publishers, dates, and links.

## Technology Stack

- Python
- Model Context Protocol (MCP)
- Google News RSS
- HTTPX
- Pydantic
